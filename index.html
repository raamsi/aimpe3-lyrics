🎵 AimpE3 Lyrics Repository

Comment ajouter des paroles ?

Pour ajouter un fichier .lrc pour votre application, uploadez-le directement dans le dossier lyrics/ de ce dépôt sur GitHub.

Le nom du fichier doit correspondre au nom de la chanson (ex: nom_de_la_piste.lrc).

Accès direct

Les paroles sont accessibles publiquement via l'API brute de GitHub pour être lues directement par votre application Android.
